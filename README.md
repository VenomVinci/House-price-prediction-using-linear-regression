# House Price Prediction using Linear Regression

## Project Overview

A machine learning project that predicts house prices using the Kaggle Housing Prices dataset.

## Dataset

* **Source:** [Kaggle Housing Prices Dataset](https://www.kaggle.com/datasets/yasserh/housing-prices-dataset)
* **Records:** 545 houses
* **Target:** `price`
* **Features:** Area, bedrooms, bathrooms, stories, parking, and other house characteristics.

## Project Workflow

1. Loaded and explored the dataset using Pandas.
2. Visualized the relationship between house area and price using Matplotlib.
3. Selected input features (`X`) and target (`y`).
4. Split the data into training and testing sets.
5. Handled missing values and encoded categorical features.
6. Trained a Linear Regression model using Scikit-learn.
7. Evaluated predictions using MAE and R².

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn

## Goal

To learn the complete machine learning workflow, from data exploration and preprocessing to model training, prediction, and evaluation.
